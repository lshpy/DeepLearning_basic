# DeepLearning_basic

Colab notebooks from working through introductory machine learning (scikit-learn), following the Korean textbook *혼자 공부하는 머신러닝+딥러닝* by Haesun Park (datasets from [rickiepark/hg-mldl](https://github.com/rickiepark/hg-mldl)).

| Notebook | Topic |
|---|---|
| `3_2.ipynb` | k-nearest neighbors on the fish dataset; train/test split and feature standardization |
| `3_3.ipynb` | Multiple regression with polynomial features; ridge and lasso regularization |
| `4_1.ipynb` | Logistic regression: binary and multiclass classification, sigmoid and softmax |
| `4_2.ipynb` | Stochastic gradient descent (`SGDClassifier`), epochs and over/underfitting |
| `5_1.ipynb` | Decision trees on the wine dataset |
| `5_2.ipynb` | Cross-validation, grid search and random search |
| `5_3.ipynb` | Tree ensembles: random forest, extra trees, gradient boosting, histogram-based boosting (XGBoost, LightGBM) |
| `6_1.ipynb` | Clustering the fruit image dataset by mean pixel values |
| `6_2.ipynb` | k-means clustering and the elbow method |

## Running

Open any notebook in Google Colab (each has a Colab badge) or locally with Jupyter. Dependencies: `numpy`, `pandas`, `matplotlib`, `scikit-learn`, `scipy`; `5_3` also uses `xgboost` and `lightgbm`. Data is downloaded from the URLs inside the notebooks.
